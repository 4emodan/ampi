# Ampi

Ampi is a personal AI assistant that one person runs for themselves. It is reached through a private Telegram
bot, runs on its owner's own server, and uses the official Claude Code CLI with the owner's Claude subscription.

It is not a service for other people: there are no user accounts, no sign-up, and nobody but the owner can talk
to it or connect an account to it.

## What it does

- Chats in Telegram, with separate conversations, files and memory.
- Reads and organizes the owner's Todoist and Gmail when the owner connects them; anything that sends, deletes or
  changes something important asks the owner first with Approve / Reject buttons.
- Runs "watchers": small automations the owner approves (for example, a summary of each email from a school).
- Optional integrations the owner can turn on: Telegram, YouTube, Google Maps, Wolt, Threads, Instagram, a sandboxed
  web browser, and checkout with the owner's approval.
