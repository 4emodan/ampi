# Requirements

## 1. What should it do?
* Be able to work with different users - my family members. So each user should have her own everything except the subscription - they'll use mine.
* Support creating different long-running chats with a user - not tied up to a single chat
* Conduct complex long-running researches/searches
-

## 2. How do I talk to it?
* Support WhatsApp, maybe through MCP
* Support rich content - images, video, files
-

## 3. Proactive / scheduled tasks
* Schedule repeating tasks and be able to keep record of them. So when a task ran, and user writes about it - the assistant should know what she's talking about. 
* Also to act upon repeating tasks. E.g. set a task to monitor email feed and to notify if there's something about a specific order.
-

## 4. Memory
* Anything user asks to remember.
* Same way the claude memory works - past convos, user's preferences, etc.

-

## 5. Integrations
* Gmail, Google Calendar, Todoist, Telegram, Youtube, local files, web search

## 6. Permissions and safety
* Sending emails or any messages on behalf of a user
* Deleting anything - emails, files, calendar events, etc.

-

## 7. Personality and language
* Should be configurable per user
-

## 8. Limits
* Should be configurable per user
-

## 9. Nice to have / later
* A companion mobile app to act on a mobile phone - set alarms, geo-location rules, make calls, audio-convos, etc.
